# BROMAX's Lib

Player animation library for BROMAX's combat mods (used by [BHB](https://github.com/monroelogs984-maker/bhb)'s
1.12.2 Forge branch). Houses the shared `com.bromax.bromaxlib.accessor` mixin-accessor
interfaces used to bridge protected vanilla methods without `@Invoker` (which breaks at
runtime against the obfuscated jar — see this machine's CLAUDE.md for the pattern).

Minecraft 1.12.2, Forge. No license currently declared in `mcmod.info`.
